# 정부과제 매뉴얼 검색 도구 — 설치 안내

Claude Desktop 이 국가연구개발혁신법 매뉴얼 5종을 직접 찾아보고
**쪽번호와 함께** 답하게 해주는 도구입니다.

---

## 준비물

**파이썬** 이 설치되어 있어야 합니다. 없으면 아래에서 받아 설치해주세요.

https://www.python.org/downloads/

> 설치 화면 **맨 아래 `Add python.exe to PATH` 를 반드시 체크**하고 진행하세요.
> 이걸 놓치면 설치가 안 됩니다.

이미 설치되어 있는지 모르겠으면 그냥 3번으로 가세요. 없으면 알려줍니다.

---

## 설치

**1. 압축을 풉니다**

`C:\정부과제매뉴얼검색` 처럼 **짧고 한글이 적은 경로**에 푸는 게 좋습니다.

> `문서`, `바탕화면`, `OneDrive` 폴더는 피해주세요.
> 클라우드 동기화가 걸려 있으면 문제가 생길 수 있습니다.

**2. Claude Desktop 을 완전히 종료합니다**

창을 닫는 것만으로는 부족합니다.
작업표시줄 오른쪽 아래 아이콘을 **우클릭 → 종료** 해주세요.

**3. `deploy` 폴더의 `install.bat` 을 더블클릭합니다**

검은 창이 뜨고 아래처럼 진행됩니다. 몇 분 걸립니다.

```
[1/5] 파이썬 확인            OK
[2/5] 가상환경 생성          OK
[3/5] 패키지 설치            OK
[4/5] 동작 점검              OK
[5/5] Claude Desktop 등록    OK
```

중간에 `실패` 가 나오면 **그 화면을 그대로 캡처해서 보내주세요.**

**4. Claude Desktop 을 다시 켭니다**

## 잘 됐는지 확인

Claude 에 이렇게 물어보세요.

```
국가연구개발사업에서 중소기업 기술료율이 얼마야?
```

**정상이면** 이런 식으로 답합니다.

> 별권2 기술료제도 5~6쪽에 따르면, 제3자 실시의 경우 중소기업은
> 기술료 징수액의 **2.5%** 이고, 납부 상한은 정부지원연구개발비의 10% 이하입니다.

**쪽번호가 나오면 성공입니다.**
쪽번호 없이 두루뭉술하게 답하면 도구를 못 쓰고 있는 겁니다.

## 안 될 때

`deploy` 폴더의 **`점검.bat`** 을 더블클릭하면 상태를 알려줍니다.

```
  패키지 불러오기          OK
  검색 데이터              OK   32.4MB
  색인                     OK   섹션 211 · 청크 1148
  검색 동작                OK   '기술료율' → v2 p5~6
  의미 검색                OK   정상
```

`의미 검색` 이 **"사용 불가 — 키워드 검색으로 동작합니다"** 로 나와도
**고장이 아닙니다.** 회사망에서 외부 접속이 막힌 경우이고, 검색은 계속 됩니다.
다만 질문 표현이 매뉴얼 용어와 다르면 잘 못 찾을 수 있습니다.

그 밖의 문제는 점검 결과를 캡처해서 보내주세요.

## 알아두실 점

- 이 도구는 **개인 포트폴리오 프로젝트**이며 공식 정부 서비스가 아닙니다.
  중요한 판단은 반드시 원문과 담당 부처 안내를 확인해주세요.
- 매뉴얼은 2026년 4월 발행본 기준입니다.
- 서식(양식)은 **수록 위치만** 알려주고 내용은 담고 있지 않습니다.
- 질문하신 내용 중 검색에 쓰이는 부분은 외부 서비스로 전송됩니다.
  회사 기밀이 포함된 질문은 피해주세요.
